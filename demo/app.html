About the Project

What is a
Virtual Assistant?

An AI-powered software that understands natural language, classifies intent using machine learning, and executes tasks automatically — all in under one second.

01

Listen

Microphone captures audio, Google Speech API converts it to text instantly.

02

Understand

TF-IDF + Naive Bayes ML model classifies intent with confidence score.

03

Execute

9 task handlers run the correct action — search, calculate, report, and more.

04

Respond

Text-to-Speech converts the result back to voice output through speakers.

Architecture

7-Step
Pipeline

01

Voice Input

Microphone captures audio waves from the user

02

Speech Recognition

Google API converts audio → text string

03

Text Processing

Clean, lowercase, normalize the text

04 AI Core ★

ML Classification

TF-IDF vectorizes text → Naive Bayes predicts intent with confidence

05

Task Routing

Routes to the correct handler function

06

Task Execution

Performs the action — search, calculate, log

07

Voice Response

Text-to-Speech speaks the answer back
